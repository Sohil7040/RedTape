# UI redesign implementation report — 26 October 2026

This report records its implementation checkpoint. For the latest release, test totals, blank startup and follow-up repairs, see [current status](CURRENT_STATUS.md). The later [Knife/pattern and native upload audit](KNIFE_PATTERN_UPLOAD_FIXES.md) supplements the findings below.

Corelith now uses Design → Laser → Preview & Send in the actual React application. The same document, editor store, canvas engine and manufacturing pipeline serve all three workflows. No project schema migration or new dependency was needed. Source and previous installed releases are preserved.

## Implemented

- Compact workflow header with meaningful Saving locally / Saved locally / Save failed status. Save failures expose their real cause. Autosave still uses the compatible local-storage envelope; no cloud sync claim.
- Contextual primary actions: Prepare Laser Job, Preview Job and Upload to Machine. The last opens connection/review; only the explicit storage-upload button invokes the existing sender after a verified handshake.
- Grouped drawing/edit/navigation rail, searchable Objects tree, Objects/Sheets panel and reusable collapsible inspector. Layer colour/transfer, visibility, locking and stacking remain accessible. Sheet creation, naming, sizing, switching and deletion remain functional; no empty Assets subsystem.
- Fit Sheet / Selection / All / Actual size using existing millimetre bounds and viewport transforms. Aspect-ratio lock uses existing selection scaling. Node, snapping, Knife and pattern controls remain available. Advanced sections collapse without deleting settings.
- Built-in font families are labelled as bundled compatible families. Font weights now expose the actually supported Regular and Bold options. Existing alias values remain compatible.
- Grouped native export dialog: project backup, active-sheet artwork, generated manufacturing files. Existing RD/DXF/PLT/SVG/PNG/job JSON/project exporters are reused. RLD remains explicitly unavailable.
- Compact operation rows with object counts, independent speed, minimum/maximum power, passes, air assist, built-in preset application and existing advanced settings. Applying a preset explicitly replaces process values; values are not represented as machine-validated recommendations.
- Optimization, kerf, leads/overcut, engraving, sequencing, geometry quality and shelf nesting organized under focused sections. The nesting diagram is calculated from existing placements and reports unplaced objects and rectangular bounding-box coverage.
- Preview summary, theoretical time/breakdown/allowance, complete ordered execution list, selection highlighting and theoretical simulation preserved. Removed repeated workflow bars, decorative telemetry and canvas instruction banners.
- Error/warning/information validation presentation reuses actual preflight output. Where a message identifies an object or layer, Select object / Review layer actions are available. Successful RD generation is distinct from machine verification.
- Connection review shows the selected sheet, actual destination, filename, dimensions, generated bytes, validation and estimated duration. Actual acknowledged progress and readback status are retained. Mismatched bytes report upload completed but verification failed; unavailable readback is a warning, not verified success. No automatic resend added.
- Reusable light/dark tokens, visible focus, persistent panel/section preferences, command search (Ctrl/Cmd+K), focus containment/restoration for existing custom dialogs, and native modal command/export dialogs.
- Desktop-first responsive layout. Below 980 px, panels initially collapse and open one at a time. The contextual toolbar scrolls locally when needed; small-screen production work remains best performed on a larger display.

## Preservation and boundaries

Geometry, snapping mathematics, Knife topology, pattern transformations, curve fidelity, laser ordering/kerf/hatching, supported imports, export encoders, network protocol, uploader and bridge remain authoritative. Presentation transitions do not alter RD bytes or add undo edits. Undo/redo keeps the current workspace display consistent. Existing 88 tests continue to pass.

Source `Audit Workflow` was restored after the temporary 20→30 mm aspect-lock test; it still has two original objects, two layers and two sheets. Simulation testing was entirely theoretical. No controller probe, upload, storage write, motion, frame or firing command was sent. Machine transfer tests use mocks. There are no new remote motion controls.

## Remaining scope

Material preset CRUD/import/export, reusable asset management, sheet duplication and group/ungroup were not present and have not been represented as completed features. Advanced operation controls for unsupported dot/pen or micro-tabs retain explicit export blocking. Native grayscale photo engraving, lossless PDF vectors, full font/script shaping, shape-aware nesting, calibrated acceleration timing, native RLD export and automatic LCD refresh remain unsupported. Use Esc → File → select filename at the cutter after uploads. Existing built-in presets require operator calibration.
